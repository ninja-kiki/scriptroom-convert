# scriptroom convert (로컬)

영화 각본 PDF + 자막을 받아 **포맷 → 한국어 번역**으로 변환하는 로컬 도구.
번역은 **Claude Max/Pro 구독**(`claude` CLI)으로 돌아갑니다. **API 키 불필요, 토큰 종량제 과금 없음.**

---

## 1. 미리 준비 (한 번만)

1. **Node.js** 설치 — https://nodejs.org (LTS)
2. **Claude Code CLI** 설치 + 본인 계정 로그인
   - 설치: https://claude.com/claude-code
   - 터미널에서 `claude` 실행 → 로그인 (Max 또는 Pro 구독 계정)
   - ✅ 이게 핵심입니다. **로그인이 안 돼 있으면 번역이 안 돌아갑니다.**
   - 번역은 **본인 구독 사용량**을 씁니다 (각자 자기 계정).

> 확인: 터미널에서 `claude --version` 이 버전을 출력하면 OK.
> 화면 상단에 빨간 "Claude Code가 안 보여요" 배너가 뜨면 설치/로그인이 안 된 것입니다.

---

## 2. 실행

폴더 안에서:

```bash
./launch.sh
```

- 처음 실행 시 자동으로 `npm install` (의존성 설치, 1~2분)
- 로컬 서버 + 화면이 뜨고 브라우저가 **http://localhost:5173** 으로 자동으로 열립니다
- 종료: 터미널에서 `Ctrl + C`

`launch.sh` 가 안 되면 수동으로:

```bash
npm install      # 처음 한 번
npm start        # 서버 + 화면 (http://localhost:5173)
```

## 3. 쓰는 법

### 변환 (변환 탭)
1. 각본(PDF·TXT·RTF·FDX·Fountain) + 자막(SMI·SRT, 선택)을 드롭
2. 씬 구조 확인 후 **변환 시작** → 포맷 + 번역 진행
3. 완료되면 **formatted.txt / translated.txt** 다운로드
4. 번역본은 리더(scriptroom)로 가져가 읽기/검수

### 여러 작품 동시에 (멀티세션)
- 작업은 **서버가 백그라운드로** 처리합니다. 변환을 시작한 뒤 홈으로 돌아가 **다른 작품을 또 시작**해도 됩니다.
- 홈 "작업" 목록에 진행 중·완료가 카드로 보입니다. **탭을 닫거나 최소화해도 계속** 돌아가고, 다시 열면 이어서 보입니다.
- ⚠️ 탭을 여러 개 띄울 필요 없습니다 (오히려 권장하지 않음). 한 탭에서 여러 편을 돌리세요.

### 자막은 "정답지"가 아니라 "근거"
- 한국어 자막을 넣으면, 그 자막을 **번역에 덮어쓰지 않고** 인물별 **말투(반말/존댓말)·호칭·의역 톤의 근거**로만 씁니다 (작품당 1회 "말투 가이드" 생성).
- 리더 번역 뷰에서 **점선** = 공식 자막과 정렬된 대사. **노랑 점선** = 표현이 달라 검토할 만한 줄. 클릭하면 "이 번역 vs 공식 자막" 비교가 뜹니다.

### 수정 (수정 탭)
- 완성된 `_translated.txt`를 드롭하면 **자동 진단** → 메타·러닝헤더·중복·줄나눔·**대사 속 지문 분리**를 코드로(토큰 0) 고치고, 말투 통일·직접 지시는 선택적으로 AI 수정.
- 리더에서 내보낸 `_수정요청.json`도 드롭하면 AI 교정 후 오버레이를 만들어 줍니다.

### 문제가 생기면
- 일부 씬이 실패하면 **오류·경고 요약**에 종류별(네트워크·로그인 필요·한도 등)로 모여 보입니다. **재시도**는 서버가 이어서 처리합니다.
- 설정(우상단)에서 **번역 모델 / 동시 처리 수 / 라이트·다크 / 지침** 조정.

## 참고

- **요금**: 본인 Claude 구독 사용량만 소모. 별도 API 키·결제 없음.
- 번역 지침/용어는 `prompts.json` 에 들어 있어 클론하면 그대로 공유됩니다.
- 진행 중 작업 상태는 `jobs/` 폴더에 저장되어 서버를 재시작해도 이어집니다 (git에는 안 올라감).
- 큰 각본은 시간이 좀 걸립니다 (씬 수에 비례).
